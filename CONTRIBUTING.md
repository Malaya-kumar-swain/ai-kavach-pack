# Contributing

Thank you for helping make AI governance practical.

## Good first contributions
- Improve the wording of a checklist line or a gap message
- Add a fictional example system for a new sector
- Suggest a gap rule, with the reason and a source

## Ground rules
- Legal and regulatory references must cite the official source. When in doubt, leave it out.
- No real company systems or internal documents in examples. Keep examples fictional.
- Keep the core free of outside dependencies.

## Setup
```bash
pip install -e ".[dev]"
pytest -q
```

Please open an issue before a large change, so we can agree on the approach first.
